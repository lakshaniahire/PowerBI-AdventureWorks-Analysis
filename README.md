# Adventure Works Sales Analysis – Power BI

## 📊 Project Overview

This project analyzes Adventure Works sales data using Microsoft Power BI.

The objective is to understand sales performance, profitability, product performance, customer behavior, and regional sales trends through an interactive dashboard.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
* Microsoft Excel

## 🎯 Business Objectives

* Analyze overall sales performance
* Identify top-performing products
* Analyze sales by region and customer
* Compare sales and profit performance
* Analyze sales trends over time
* Track important business KPIs


## 🔑 Key Skills Demonstrated

* Data Cleaning
* Data Transformation
* Power Query
* Data Modeling
* DAX Calculations
* KPI Development
* Interactive Data Visualization
* Business Intelligence

## 📂 Project Files

* `PowerBI/` – Power BI dashboard file
* `Screenshots/` – Dashboard screenshots
* `README.md` – Project documentation

## 📌 Project Outcome

The dashboard provides an interactive view of Adventure Works sales performance and helps identify important trends and business insights.
